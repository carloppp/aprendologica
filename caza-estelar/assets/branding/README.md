# Identidad visual

## Logo aprobado

`tojil-face-logo-final-hq-rounded.png` es el logo maestro de Tojil aprobado para **Caza Estelar**.

Tiene mayor resolución, curvas refinadas y esquinas redondeadas con transparencia real. `tojil-face-logo-final.png` se conserva como referencia original de baja resolución.

Debe conservarse sin alterar:

- el encuadre vertical actual;
- la espiral superior;
- los dos detalles de fuego superiores espejados;
- los ojos azul marino;
- la sonrisa blanca pequeña;
- el fondo naranja de borde a borde.

Los archivos con sufijos `v2`, `v3` y `v4` son exploraciones previas y no deben utilizarse en producción.

## Icono de Android

`tojil-app-icon-square-preview.png` documenta el recorte cuadrado utilizado por el lanzador. Es naranja de borde a borde y no contiene transparencia, para evitar franjas blancas en dispositivos que rellenan los márgenes del icono.
